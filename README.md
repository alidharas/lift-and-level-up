# Lift And Level Up

lets make a gym based app just for myself, that tracks all my weights and workouts when i go. i want it to include an upper body workout, a lower body workout, a glute focused workout, a hip focused workout, and can track my progress. use this for reference on the exercises, include the videos as tappable links. let me swap or remove exercises based on what my gym has available as well
